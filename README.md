# Desafío 2 — Ahorcado y sistema de notas

Aplicación de consola desarrollada en C# para la asignatura PAL404. Integra dos ejercicios en un menú principal y aplica fundamentos de programación estructurada.

## Módulos

### Juego del Ahorcado

- Selección de palabras.
- Control de intentos y letras utilizadas.
- Validación de entradas.
- Mensajes de victoria o finalización del juego.

### Sistema de registro de notas

- Registro de estudiantes y calificaciones.
- Cálculo de promedios.
- Presentación de resultados en consola.
- Validación de los datos ingresados.

## Tecnologías y conceptos

- C# y .NET
- Aplicaciones de consola
- Métodos, arreglos y ciclos
- Condicionales y menús
- Validación de entradas

## Ejecución

Requisitos: Git y el SDK de .NET.

```bash
git clone https://github.com/iCreb2512/Desafio_CR260127_MR260120.git
cd Desafio_CR260127_MR260120
dotnet run
```
